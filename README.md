# CS7643-DL-Final
Repository to host our code and output for our final project

## Usage

Build the docker image:

`docker build -t cs7643-dl-final .`

Spin up the containers:

`docker compose up -d`

Open `http://127.0.0.1:8080/docs` in your browser to view interactive API
documentation.

Stop the containers:

`docker compose down`
